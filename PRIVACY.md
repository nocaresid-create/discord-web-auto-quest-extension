# 🔒 Privacy Policy

**Discord Web Auto Quest Extension**

**Last Updated:** August 4, 2026

---

## Your Privacy Matters

Your privacy is simple:

> **This extension does not collect, store, track, or share any of your personal data.**

Everything happens **locally inside your browser**.

No analytics. No trackers. No external servers.

---

## What This Extension Does

The extension only works on **https://discord.com/** and is designed to automate Discord Quests.

It can:

- 🎯 Automate supported Discord Quests
- 🖥️ Pretend to be the Discord Desktop app by modifying the `User-Agent`
- 📜 Inject a helper script into the Discord page
- 🔄 Send Quest progress requests directly to Discord's official API
- 📊 Display a progress panel on the Quest page

That's it.

## Permissions Explained

The extension only requests permissions required for its features.

### `https://discord.com/*`

Allows the extension to work only on Discord pages.

### `Scripting`

Used to inject the helper script into Discord.

### `ActiveTab`

Allows the extension to access the currently open Discord tab.

### `DeclarativeNetRequestWithHostAccess`

Used to modify the `User-Agent` so Discord treats the browser like the desktop app.

These permissions are **never** used for tracking or collecting information.
